# E-commerce-Sales-Analysis :-

📊 E-Commerce Sales Dashboard (Power BI)

📌 Project Overview

This project presents an interactive E-Commerce Sales Dashboard built using Power BI to analyze sales performance, profit trends, customer channels, and regional insights.
The dashboard helps stakeholders quickly understand where revenue is coming from, which products are most profitable, and how performance changes over time.
This is a self-driven (unguided) project created to strengthen my data analysis and visualization skills.


🎯 Business Objective
* To analyze e-commerce sales data and provide actionable insights on:
* Overall sales and profitability
* Monthly sales trends
* Product-wise sales vs profit comparison
* Channel performance (Online, In-Store, Outlet)
* State and region-wise sales distribution

📈 Key KPIs
Total Sales: ₹1.36M
Units Sold: 2,513
Operating Margin: 20%
Operating Profit: ₹279.1K

📊 Dashboard Insights
🔹 Sales Trend Analysis
Sales peaked during early months (Jan–May).
A noticeable decline occurred around June–July, followed by gradual recovery.

🔹 Region-Wise Performance
West and North regions contributed the highest sales.
South and East regions show growth opportunities.

🔹 Product Performance (Sales vs Profit)
T-Shirts and Running Shoes generated high revenue with strong profit margins.
Jackets and Bags showed relatively lower profit contribution.

🔹 Channel Contribution
In-Store: 35.71% (Highest)
Outlet: 31.81%
Online: 32.48%

👉 Offline channels still dominate sales.

🔹 State-Wise Sales
Strong performance from Maharashtra, Karnataka, Tamil Nadu, Delhi, and Uttar Pradesh.


🛠 Tools & Technologies Used
Power BI
Power Query (Data Cleaning & Transformation)
DAX (Calculated Measures & KPIs)
Excel / CSV Dataset
